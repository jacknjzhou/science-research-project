## 1. 范围与依赖

本模块覆盖跨域独立档案库，核心链路为
**"文档上传(MinIO) → 建案卷 → 门类清单/来源摄取 → 提交 → 四性检测 → 入库 → 借阅/检索/销毁"**。

| 编号 | 功能 | 优先级 | 本文落点 |
|------|------|--------|----------|
| O-01 | 电子文档上传/下载/删除/全文检索 | P0 | §2 o_document、§5 文档端点 |
| O-02 | 案卷台账 CRUD | P0 | §2 o_archive、§5 案卷端点 |
| O-03 | 归档门类清单（必填齐备性） | P0 | §2 o_archive_item、§5 items |
| O-04 | 来源摄取（引用已上传 document） | P1 | §5 ingest |
| O-05 | 四性检测（真实性/完整性/可用性/安全性） | P0 | §4 四性算法、o_archive_check |
| O-06 | 归档状态机（提交/检测/入库/销毁） | P0 | §3 状态机 |
| O-07 | 借阅申请与审批 | P0 | §2 o_borrow、§5 borrows |

**与 E 边界**：`E_PROJECT_DOC`/`E_ARCHIVE_CHECKLIST` 属项目过程内文档，留 E 域；O 以「案卷」为单位，
`source_module + source_id` 逻辑指回任意来源对象。二者不重叠，O 可摄取 E 文档作为来源之一。

## 2. 数据表（对齐 DDL）

- **o_document**：电子件元数据（对象存储）。通用列 + `security_level`。业务列 `name/doc_type/size_bytes/bucket/object_key/checksum_sha256/uploader_id/uploaded_at/source_module(逻辑)/source_id(逻辑)/text_content(抽取正文,仅检索不外泄)/status(UPLOADING/STORED/MISSING)`。唯一 `uk_o_doc_key(tenant_id,bucket,object_key) WHERE deleted=0`、`uk_o_doc_code`；GIN 全文索引 `idx_o_doc_fts(to_tsvector('simple',text_content))` + `idx_o_doc_trgm(gin_trgm_ops)`（依赖 00-common §0 `pg_trgm`）。
- **o_archive**：案卷。通用列 + `code(ARC-年-序)/security_level`。业务列 `title/archive_type(PROJECT/OUTPUT/EXPENSE/CONTRACT/ACTIVITY/OTHER)/source_module/source_id/source_code/owner_dept_id/retention_years/submitter_id/submit_at/archivist_id/filed_at/status`。状态机见 §3。唯一 `uk_o_arc_code`；索引 `(tenant_id,status)`、`(source_module,source_id)`、`(tenant_id,archive_type)`。
- **o_archive_item**：门类清单条目。`archive_id→o_archive`、`doc_id→o_document(可空=缺)`、`category_code(门类,sys_dict)/category_name/required/sort_no/status(MISSING/FILLED/CHECKED)`。唯一 `uk_o_item(archive_id,category_code)`。
- **o_archive_check**：四性检测报告。`archive_id→o_archive`、`check_type(AUTHENTICITY/INTEGRITY/USABILITY/SECURITY)`、`result(PASS/FAIL/WARN)`、`detail(JSONB)`、`checked_at/checker_id`。唯一 `uk_o_check(archive_id,check_type)`（幂等 upsert）。
- **o_borrow**：借阅申请。通用列 + `code(BORROW-年-序)`、`archive_id→o_archive`、`borrower_user_id/purpose/borrow_type(READ/COPY)/approved_by/approved_at/due_at/returned_at/status(SUBMITTED/APPROVED/REJECTED/RETURNED/EXPIRED)`。索引 `(archive_id,status)`、`(borrower_user_id,status)`。

## 3. 案卷状态机

`PENDING_SUBMIT → SUBMITTED → CHECKING → PASSED → ARCHIVED → DESTROYED`；分支 `CHECKING → REJECTED →(补正) SUBMITTED`。

- `PENDING_SUBMIT/REJECTED → SUBMITTED`：`submit`（编辑/删除仅在此二态允许）。
- `SUBMITTED → CHECKING → PASSED/REJECTED`：`check` 执行四性检测（§4），全 PASS → PASSED，否则 → REJECTED。
- `PASSED → ARCHIVED`：`file`（档案员确认入库）。
- `ARCHIVED → DESTROYED`：`destroy`（到期销毁，`reason` 留痕，需审批）。
- 所有状态迁移用 `SetArchiveStatus` 乐观并发：`WHERE status = from_status`，0 行 → 40901。

借阅 `o_borrow` 独立状态机：`SUBMITTED → APPROVED/REJECTED`；`APPROVED → RETURNED`；逾期未还 → `EXPIRED`。

## 4. 四性检测算法（纯函数，无 DB/MinIO）

`evaluateFourProperties(facts) []checkResult`（`check.go`），喂组装好的事实：

- **AUTHENTICITY**：逐文档 `Expected(checksum_sha256) == Got(实取 MinIO 字节算 sha256hex)`；任一不符 → FAIL（记 `mismatch_doc_ids`）。
- **INTEGRITY**：`required` 门类齐备性 `RequiredFilled >= RequiredTotal`？不足 → FAIL。
- **USABILITY**：格式可读 `docTypeUsable(doc_type) || text_content 非空`；全不可读或无件 → FAIL，部分不可读 → WARN，全可读 → PASS。
- **SECURITY**：`SecurityOK`（案卷密级在操作人 clearance 内；本轮：非 TOP_SECRET 或操作人含 R-ADMIN）；否 → FAIL。

`allPassed(res)` 供 handler 判定 `CHECKING→PASSED/REJECTED`；`byType(res,typ)` 取单项。二者与 `evaluateFourProperties` 同置生产文件 `check.go`（非 `_test.go`，避免同包重复声明）。
`CheckArchive` handler：`ListRequiredItems` 算 required 事实 → 过滤 FILLED 条目逐 `GetDocument` → `h.store.Get` 取字节算 Got → 组装 facts → `evaluateFourProperties` → 逐条 `UpsertCheck` → 状态迁移 → `WriteOK({list,passed})`。

## 5. 端点（tag: archive）

文档：`POST /documents`（multipart 上传→Put→写 o_document→返回 Document）、`GET /documents/{id}`、`GET /documents/{id}/download`（presigned URL，`data:{url,expires_at}`）、`DELETE /documents/{id}`（软删 + 尽力删对象）、`GET /documents/search`（全文检索，返回 Document + snippet/rank）。

案卷与归档流程：`GET/POST /archives`、`GET/PUT/DELETE /archives/{id}`、`GET/POST /archives/{id}/items`、`PUT/DELETE /archives/{id}/items/{itemId}`（fillItem 用 **PUT**）、`POST /archives/{id}/ingest`、`POST /archives/{id}/submit|check|file|destroy`。`check` 返回 `data:{list:[ArchiveCheck],passed:boolean}`。

借阅：`GET/POST /borrows`、`POST /borrows/{id}/approve|reject|return`。

列表端点 `data` 用自包含 typed PageResult（base `PageResult{total,page,size}` + 端点内 `allOf` 覆写 `list` 项型），与 M/N 同款，**PageResult.items 保持通用不钉死**，规避 R/S pinned PageResult 枚举/可空组合冲突致 verify 报错。

## 6. 对象存储接线（storage 注入）

- `Handler{q *ostore.Queries; store storage.Storage}`；`NewHandler(pool, s)`，`s` 可为 nil。
- `guardStorage(c)`：`store==nil` → `WriteErr(503,50301,"对象存储不可用")` 返 false（上传/下载/删除/检测依赖点先行）。
- 上传：`c.FormFile("file")` → 读字节算 `sha256`（`crypto/sha256`+`hex`）→ objectKey=`tenant/{tid}/{unixnano}-{base}` → `store.Put` → `CreateDocument(status=STORED,checksum,bucket=ark-docs,object_key,size_bytes,doc_type,...)`。
- 下载：`store.PresignGet(key)` → `{url,expires_at=now+15min}`。
- 删除：软删 0 行→40401 → 尽力 `store.Remove(key)`（失败仅日志，不回滚软删）。

## 7. 权限（Casbin）

- 上传/建案卷/提交：R-STAFF（本人来源对象关联）。
- 四性检测/入库/销毁：R-ADMIN（本轮复用 R-ADMIN/R-MANAGER，避免角色枚举漂移，规格 §6.3）。
- 借阅审批：R-MANAGER/R-ADMIN；借阅人：登录用户（ABAC 密级 + 案卷可见性）。
- 检索：ABAC tenant + security_level（涉密案卷仅对应密级可见）。
