## 一、平台概述

**一体化科研管理平台（CoNow-AOP: Academy Operating Platform）** 由科南软件推出，是专门面向科研机构的一体化综合管理与服务平台，其核心定位与能力包括：

- 实现科研项目管理的**全程协同**；
- 以项目为中心，形成经费预算、费用支出、财务核算和项目决算的**闭环式科研经费合规化管理**；
- 实现资产与耗材从采购、使用、核算到项目成本分摊的**全生命周期管理**；
- 以人为中心，提供人事管理与薪酬的**全程服务**；
- 满足办事、办会、办文和沟通的**协作办公环境**。

平台是科研管理信息化最完整的一体化解决方案，填补了我国科研事业单位专业信息化平台的空缺。

## 二、核心功能模块（六大领域）

### 1. 科研与项目

满足科研院所的科研项目（纵向项目、横向项目、自主项目等）**开题与实施、阶段检查与验收结题**的全过程管理与服务。

**功能要点：**

- 覆盖纵向、横向、自主等多类型科研项目；
- 项目全生命周期：立项开题 → 过程实施 → 阶段检查 → 验收结题。

### 2. 预算与财务

实现**预算（事前）、报销（事中）、会计（事后）**的闭环财务管理，满足科研经费的专款专用、项目核算以及政府会计制度的合规管理，实现**财务业务一体化**。

**功能要点：**

- 事前预算编制与控制；
- 事中费用报销与支出管理；
- 事后会计核算与项目决算；
- 科研经费专款专用与项目级核算；
- 符合政府会计制度的合规管理。

### 3. 采购与合同

针对资产、耗材及服务等不同类型采购对象，支持**采购计划、采购申请与报批、采购订单与执行、采购合同签订与履约**等全过程的管理服务。

**功能要点：**

- 多采购对象类型：资产、耗材、服务；
- 采购计划管理；
- 采购申请与审批报批；
- 采购订单与执行跟踪；
- 采购合同签订与履约管理。

### 4. 资产与耗材

提供固定资产、无形资产、耗材的**验收入库、登记、领用、维修保养到处置**的全生命周期管理，实现资产的**折旧与核算**等账实一致的管理服务。

**功能要点：**

- 资产类型：固定资产、无形资产、耗材；
- 全生命周期：验收入库 → 登记 → 领用 → 维修保养 → 处置；
- 资产折旧与财务核算；
- 账实一致管理。

### 5. 组织与人才

以人才为中心，提供**人事事务、时间管理、人才发展**等全职业生涯的管理服务。

**功能要点：**

- 人事事务管理；
- 时间管理；
- 人才发展与全职业生涯管理；
- 与薪酬体系联动（见平台概述）。

### 6. 行政与办公

实现**无纸化、移动化**的行政管理与协作办公服务，提供**办事、办文、办会**及**可自定义行政事务审批流程**的管理。

**功能要点：**

- 无纸化、移动化办公；
- 办事、办文、办会三办服务；
- 可自定义配置的行政事务审批流程。

## 三、产品特性与优势（六大特性）

### 1. 业务功能的专业化

- 科研信息化与政府信息化、企业信息化相比，在**业务模式、应用架构和业务流程**上表现出独特的个性化；
- 以往科研信息化建设或基于数字化办公的**政务模式**，或基于通用 ERP 的**企业模式**，针对科研事业单位的特殊管理模式与个性化需求，长期缺乏专业性解决方案；
- 本平台是专门针对科研单位的**管控模式、业务需求、功能应用**等行业化特色与个性化需求的一体化专业解决方案，并在新一代信息技术基础上实现业务与技术的整体升级换代。

### 2. 应用架构的一体化

- 科研机构的管理是围绕科研活动、以项目管理为主线的管理模式，将人员组织、财务核算、预算控制、成本分摊、成果统计等各项管理，以**项目或课题为管理维度**；
- 一体化架构的核心是实现**纵向管理与横向业务协作的一体化**：
  - **纵向一体化**：通过云计算架构，实现院所两级多法人业务的融合；
  - **横向一体化**：围绕科研活动的流程与要素，实现端到端的业务流程。

### 3. 使用体验的人本化

- 通过科研活动的业务过程与服务流程积累的数据直接进行分析和提取，**避免一线大量表格填写和上报**的工作量；
- 大大提高统计分析与决策支持的效率，保证数据准确性，**降低一线科研人员的数据采集工作量**；
- 传统 ERP 以**职能管理**为中心，现代互联网和云计算时代 IT 运行以**角色**为中心，增进人与人协作关系，基于角色与信息关联的联结、聚合，增进业务协作效率和知识创新；
- 平台融合社交化和业务服务，搭建一体化的深度业务协作平台。

### 4. 基础平台的信创化

- 技术路线采取**完全开放的架构**，在全栈适配信创软硬件环境的同时，**支持但不绑定 WinTel/IOE 架构**；
- 采用**微服务和原生云架构**部署，解决国产硬件平台单机性能不高的问题，运行软件具备分布式和负载均衡的横向扩展能力；
- 对涉密应用中的**用户管理、三员管理、日志安全、安全审计、身份鉴别、涉密信息流向控制**等需求，从核心架构、基础组件、功能开发等方面提供可信、安全的应用架构。

### 5. 网络安全的多域化

- 不同业务系统共享计算网络资源，但各自面临不同的资产价值、安全威胁、安全弱点问题；为避免某一业务系统的安全问题影响其他业务系统，需要做好**安全域划分**，实现网络安全隔离和防护；
- 根据网络安全分区、分域管理原则，结合科研项目及科研管理的业务特色，平台支撑**三个网络安全域**：
  1. 互联网安全域；
  2. 办公内网安全域；
  3. 涉密网安全域。

### 6. 技术架构的平台化（三中台架构）

| 中台 | 能力说明 |
| --- | --- |
| **技术中台** | 采用微服务架构与低代码开发平台，支撑系统开发的快速迭代与系统架构的整体集成，实现可持续的业务扩展 |
| **业务中台** | 对业务与应用管理中的共性组件进行统一管理和服务；支持多组织、多租户的应用与数据架构；支持可配置的业务规则、业务流程和应用模板，满足业务的灵活性 |
| **数据中台** | 提供对数据采集、存储、编码和访问的统一封装，并提供分析与可视化服务，实现数据业务化、资产化 |

## 四、技术积累与背景（补充：官网首页信息）

以下为官网首页（`www.conow.cn/index.html`）中与该平台相关的补充信息：

- 平台 AOP 是**中国科学院为替换 Oracle ERP 而全新研发的新一代 ARP 系统**的相关成果发展和产业化而来，是国内第一套专业的科研信息化解决方案；
- 平台及配套低代码开发平台（CoAPP：科南快速应用开发平台）已通过**华为鲲鹏架构和华为云的适配性测试**，获得认证标志；
- 平台是国家重点研发计划（**2021YFF090100「新型研发机构创新服务平台技术研发与应用」**）支持的创新成果；
- 配套的低代码开发平台 CoAPP 基于原生云、大数据、移动应用、人工智能等新一代信息技术研发，实现微服务架构的从低代码到无代码的快速开发，信创环境全栈适配。
